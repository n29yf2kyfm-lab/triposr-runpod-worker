Guardrails

Do's & Don'ts

Do

  • Keep the canvas near-black so imagery stays brightest
  • Reserve the gradient for the single primary action
  • Set every technical value (IDs, px, MB, hex) in Mono
  • Use the 4px spacing scale and four elevation levels
  • Keep motion physical: ease-out, 150–250ms, no bounce

Don't

  • Use pure #FFFFFF text or pure #000000 surfaces
  • Put more than one gradient in a view
  • Use weights ≥700 or decorative drop shadows
  • Show a bare spinner instead of the gradient beam
  • Stack colored glows — one accent glow per screen
